Heaven Slice website

Deploy the index.html in this ZIP as a static site.
It includes all photographs, fonts, styles and scripts.
For Vercel: put index.html in the repository root, choose Other as the
framework, enable the Build Command override and leave that command empty,
and use the root output directory. Official instructions:
https://vercel.com/docs/builds/configure-a-build
Call/WhatsApp/social links and the Google map need an internet connection.

The modular source is in dist/ in the project repository.
